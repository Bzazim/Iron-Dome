# כיפת ברזל — משחק חמ״ל

משחק דפדפן בעברית (RTL): השחקן מפעיל את מערך ההגנה האווירית של ישראל, מיירט איומים,
ובין הגלים מקבל החלטות קבינט, מתכנן תקיפות וחיסולים, מנהל יחסי חוץ, שיתופי פעולה ותקציב.

## מבנה
- `index.html` — כל המשחק בקובץ אחד: HTML + CSS + JS, ציור ב־canvas, בלי ספריות ובלי build.
  גבולות המדינות (Natural Earth, נחלת הכלל) מוטמעים בקובץ, כך שהמשחק עובד גם בלי רשת.
- `manifest.webmanifest`, `sw.js`, `icon-*.png`, `apple-touch-icon.png` — התקנה כאפליקציה (PWA).
- הרצה מקומית: `python3 -m http.server` ולפתוח `http://localhost:8000/`.
- פרסום: GitHub Pages מהענף הראשי, כש־`index.html` בשורש.

## מערכות במשחק
- **איומים**: רקטה, כטב״ם, טיל כבד/שיוט, טיל בליסטי. חזיתות: עזה, לבנון (בסיס), סוריה, עיראק, תימן,
  איראן, ירדן ומצרים (ניטרליות, יורות רק אחרי שתקפו אותן). מקורות שיגור במיקומם האמיתי.
- **הגנה** (`SYSTEMS`): כיפת ברזל, קלע דוד, חץ, קרן אור (לייזר, מגל 5, מיקום חופשי על המפה, בלי מיירטים).
  לכל מערכת מלאי משלה (`reserve`, `stunners`, `arrows`).
- **תקיפות** (`AIRCRAFT`, `COUNTRIES`): כמה מטוסים לכמה יעדים בבת אחת. רק מדינות (`state: true`) מפילות מטוסים.
- **חיסולים** (`LEADERS`): לפי תפקיד, עם נקמה ואחריה היחלשות (`after`), ומחליף אחרי 5 גלים.
- **לגיטימציה** (`legit`): ככל שחזית יורה יותר, תקיפה בה פוגעת פחות ביחסי החוץ.
- **יחסי חוץ** (`PARTNERS`) לפי מדינה, מפה צבועה, ופעולות דיפלומטיות (`DIPLO_*`), אחת לכל מדינה בכל גל.
- **שיתופי פעולה** (`COALITIONS`): יירוט בדרך, מודיעין, החזרת מטוסים.
- **כלכלה ותקציב**: הכנסה בכל גל לפי אמון וכלכלה; רכש מיירטים וסוללות; שיקום ערים (רגיל אחרי 3 גלים, או מואץ בתשלום).
- **הרתעה**: מורידה ירי, הרבה יותר אצל ארגוני טרור מאשר אצל מדינות.
- **צלילים**: מסונתזים ב־Web Audio (אזעקה, שיגורים, פיצוצים) והקראת ״צבע אדום״ בקול העברי של המכשיר. חלון הגדרות.
- **שמירה**: אחרי כל גל ב־localStorage (`idSave`); מסך הפתיחה מציע להמשיך.
- **אירועים באמצע גל** (`triggerEvent`): מטח לילי מאיראן, סייבר שמשבית סוללה, שיבוש GPS (נקודת פגיעה לא ידועה עד 65% מהמעוף),
  והחלטה בלחץ זמן בין בית חולים לתשתית (`DILEMMAS`, `SITE_HIT`).
- **בחירות** כל 5 גלים (`runElection`): מתחת ל־35 אמון המשחק נגמר. בגל שלפני — קלף קמפיין (`CAMPAIGN`).
- **דרגות וניקוד** (`RANKS`, `addScore`). **הישגים** (`ACHIEVEMENTS`) נשמרים בין משחקים ב־`idAch` ונותנים יתרון בפתיחה.
- **בריתות הגנה** (רשומות `COALITIONS` עם `strike`): בעלת ברית תוקפת חזית שירתה על ישראל.
  יחסים גרועים מזינים את האויב: רוסיה (סוריה, איראן), סין (איראן), קטר וטורקיה (חמאס).

## הנחיות
- ממשק בעברית, ערכת צבעים כהה טקטית, חייב לעבוד טוב בטלפון (מגע, צביטה לזום).
- לשמור על קובץ יחיד בלי build.
- כשמשנים את מבנה המצב ששומרים, להעלות את `SAVE_VERSION` כדי ששמירות ישנות לא ישברו את המשחק.
